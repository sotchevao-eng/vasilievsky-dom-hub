# Васильевский Дом

Создай современный адаптивный сайт для ТСЖ «Васильевский» на русском языке.

ЦЕЛЬ САЙТА

Сайт должен быть официальным информационным ресурсом ТСЖ и одновременно удобным сервисом для жителей дома.

Основные задачи:

— публикация новостей и объявлений ТСЖ;

— быстрый доступ к документам;

— размещение информации со стенда;

— полезные памятки для жителей;

— контакты правления;

— информация о доме и деятельности ТСЖ;

— передача обращений жителей;

— удобная навигация для людей разного возраста;

— публикация информации о собраниях собственников;

— размещение отчетов, протоколов, смет и других документов.

Не придумывай реальные адреса, телефоны, ФИО, реквизиты и даты. Используй плейсхолдеры:

и т. д.

====================

ВИЗУАЛЬНЫЙ СТИЛЬ

====================

Сайт должен визуально продолжать стиль сообщества ТСЖ «Васильевский» во ВКонтакте.

Общее настроение:

— уютный;

— современный;

— аккуратный;

— добрососедский;

— надежный;

— без ощущения типичного холодного государственного портала.

Цветовая палитра:

— теплый кремовый / светло-бежевый фон;

— приглушенный зеленый как основной фирменный цвет;

— терракотовый как акцент;

— мягкий коричневый;

— темно-зеленый для текста и важных элементов;

— белый для карточек.

Использовать много свободного пространства, мягкие скругления карточек, легкие тени, аккуратные иконки.

Стиль:

warm clean community branding,

cozy residential design,

modern homeowners association website,

soft beige, cream, muted green and terracotta palette,

friendly but professional,

minimal and readable.

Не перегружать сайт декоративными элементами.

Домового Василия можно использовать только как небольшой дополнительный элемент брендинга на главной странице или в блоке полезных советов.

Он НЕ должен присутствовать на каждой странице.

Официальные страницы документов, контактов и политики конфиденциальности должны быть без персонажа.
